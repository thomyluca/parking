# Estacionamiento

App web instalable para cobrar estacionamiento en la puerta de la fiesta.

- Buscador de patentes gratis: mesas VIP, cumpleaños y cortesías (`data.js`).
- Botones + / − para Efectivo ($10.000), Transferencia ($15.000) y Gratis.
- Muestra el total recaudado y los autos adentro.
- Todo se guarda en el celular (localStorage) y funciona sin señal (service worker).

Es un sitio estático sin build: se deploya tal cual en Vercel.
